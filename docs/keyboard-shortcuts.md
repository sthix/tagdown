# Keyboard shortcuts

## App

| Shortcut | Action |
| --- | --- |
| ⌘K | Command palette: jump to a note, search, or run an action |
| ⌘N | New note (in the selected folder; with a [type](organizing.md#note-types) selected, a note of that type) |
| ⌘⇧J | Today's journal page |
| ⌥⌘J | Quick capture: add a line to today's journal page without leaving your note |
| ⌘S | Save now |
| ⌘, | Settings |
| ⌘\\ | Focus mode (hide the sidebar and note list) |
| ⌘⇧D | Switch between light and dark theme |

## Tabs and panes

| Shortcut | Action |
| --- | --- |
| ⌘T | New tab (with the palette open to pick a note) |
| ⌘W | Close the tab; closing a pane's last tab closes the pane |
| ⇧⌘W | Close the window |
| ⌃⇥ / ⌃⇧⇥ | Next / previous tab (also ⌘⇧] / ⌘⇧[) |
| ⌘-click | Open a note, link or backlink in a new tab (⌘↩ in the palette) |
| ⌥⌘-click | Open it in a pane beside this one (⌥⌘↩ in the palette) |
| Middle-click | Open in a new tab; on a tab, close it |
| ⌥⌘\\ | Split right: the open note again, in a new pane |
| ⌃⌘← / ⌃⌘→ | Move to the pane on the left / right |

## Views

| Shortcut | Action |
| --- | --- |
| ⌘1 | Source |
| ⌘2 | Split (source and preview) |
| ⌘3 | Preview |

## Notes

| Shortcut | Action |
| --- | --- |
| ⌘⇧T | Show every open task |
| ⌘⇧H | Version history of the open note |
| ⌘⇧E | Export as HTML |
| ⌘P | Print or save as PDF |
| ⌥⌘P | Present as slides |
| ⌥⌘← / ⌥⌘→ | Previous / next day, on a journal page |
| ⌘⇧I | Fold or open the note's properties |

## Editing

| Shortcut | Action |
| --- | --- |
| `/` | Command menu: type to filter, ↑ ↓ to choose, ↩ or Tab to apply, Esc to close |
| `[[` | Wikilink autocomplete (↑ ↓ to choose, ↩ or Tab to insert, Esc to close) |
| `[[today` | Link to today's journal page (also `[[yesterday`, `[[tomorrow`) |
| Esc or ⌘↩ | Finish editing a block in the preview |
| ⌘⇧↑ / ⌘⇧↓ | Move the block you're editing up or down (a heading takes its section along) |

## Lists

| Shortcut | Action |
| --- | --- |
| ↩ | Next item of the same kind (bullet, next number, or an empty task) |
| ↩ on an empty item | Move it out a level; at the top level, end the list |
| ⇧↩ | New line inside the same item |
| Tab | Nest the item, with its children, under the item above |
| ⇧Tab | Move the item, with its children, out a level |
| ⌫ right after a marker | Turn a task into a bullet, and a bullet into plain text |

## Slides

| Shortcut | Action |
| --- | --- |
| → ↓ Space ↩ Page Down | Next slide |
| ← ↑ ⌫ Page Up | Previous slide |
| Home / End | First / last slide |
| Esc | Leave the presentation |
