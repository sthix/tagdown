# Keyboard shortcuts

## App

| Shortcut | Action |
| --- | --- |
| ⌘K | Command palette: jump to a note, search, or run an action |
| ⌘N | New note (in the selected folder) |
| ⌘S | Save now |
| ⌘, | Settings |
| ⌘\\ | Focus mode (hide the sidebar and note list) |
| ⌘⇧D | Switch between light and dark theme |

## Views

| Shortcut | Action |
| --- | --- |
| ⌘1 | Source |
| ⌘2 | Split (source and preview) |
| ⌘3 | Preview |

## Notes

| Shortcut | Action |
| --- | --- |
| ⌘⇧T | Show every open task |
| ⌘⇧H | Version history of the open note |
| ⌘⇧E | Export as HTML |
| ⌘P | Print or save as PDF |
| ⌥⌘P | Present as slides |

## Editing

| Shortcut | Action |
| --- | --- |
| `[[` | Wikilink autocomplete (↑ ↓ to choose, ↩ or Tab to insert, Esc to close) |
| Esc or ⌘↩ | Finish editing a block in the preview |

## Slides

| Shortcut | Action |
| --- | --- |
| → ↓ Space ↩ Page Down | Next slide |
| ← ↑ ⌫ Page Up | Previous slide |
| Home / End | First / last slide |
| Esc | Leave the presentation |
